# basic-chess
A basic two-player chess game in C, played in the terminal.

## Build and run
```
make
./chess_game
```

## How to play
White moves first. Each turn, type the square of the piece to move, then the square to move it to (e.g. `E2`, then `E4`).

White pieces are lowercase, Black pieces are UPPERCASE.
